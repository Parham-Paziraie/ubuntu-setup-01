# ubuntu-setup

Scripts and notes for setting up a fresh Ubuntu 26.04 machine.

## Sections

- **System setup**: `ubuntu-26.04-setup.sh`, `ubuntu-26.04-setup-asus-q540vj.sh`, `install-terminals-nautilus.sh`. `installed.md` and `commands.md` are reference notes.
- **OBS**: `ubuntu-26.04-setup-obs-vst.sh`, `obs-vst-setup.sh`, `obs-restore.sh`, `obs/`, `obs-config.md`.
- **Dotfiles (Claude Code and agent configs)**: [`dotfiles/`](dotfiles/README.md). Run `dotfiles/install.sh` to symlink them into `$HOME`.
